# Lab7Web_PHP

Praktikum 7 Pemrograman Web tentang Pemrograman Server-Side dengan PHP.

## Isi

Semua latihan dibuat dalam satu file:

- Latihan 1 - Menjalankan PHP
- Latihan 2 - Variabel, operator, dan percabangan
- Latihan 3 - Perulangan dan array
- Latihan 4 - Function
- Latihan 5 - Form dengan GET
- Latihan 6 - Form dengan POST
- Latihan 7 - Pengolahan data sederhana
- Mini Project - Formulir Data Mahasiswa

## Cara Menjalankan

1. Pastikan XAMPP/Laragon sudah terpasang.
2. Jalankan Apache.
3. Simpan folder `Lab7Web_PHP` di dalam `htdocs` jika menggunakan XAMPP.
4. Buka browser.
5. Masuk ke:

http://localhost/Lab7Web_PHP/

## Catatan

Pada Latihan 5 digunakan GET sehingga kata kunci dapat terlihat pada URL.

Pada Latihan 6 dan Latihan 7 digunakan POST. Data juga divalidasi di sisi server sebelum ditampilkan.

Mini Project memvalidasi nama, NIM, program studi, semester 1-14, dan format email.
